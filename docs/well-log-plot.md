# 最终解释曲线图

## 使用

在 AgentScope Web 上传 `mock_data/WELL_MOCK_PLOT_001.json`，输入“帮我解释这口井”。
右侧“测井解释”详情的报告上方显示“最终解释曲线”。支持全屏放大、纵向比例、
横纵滚动、悬停采样点以及 SVG 导出。历史执行选择会同步切换对应版本的图。
本次增加的样本覆盖 2000–2120 m，采样间距 0.1 m，含 1201 个合成深度点、
20 条曲线（共 24020 个采样位置）和 20 个解释层段，全部为绘图测试数据。
包含 GR、SP、CAL、DEN、CNL、AC、RT、RXO、RLLD、RLLS、PE、TOTAL_HC、
SH、SAND、LIME、DOLO、POR、PERM、SW、SOG；GR 和 AC 特意保留空值段以验证断线。
层段包含预设层组、层号、岩性和油/油水/水/干层结论。文件约 634 KiB，低于上传限制。
更新样本后需重新上传并解释；已有执行快照仍保留原数据。

布局参照用户提供的测井综合解释图：深度、分层、岩性指示、孔隙响应、光电指数/全烃、
电阻率、取心、岩性剖面、组分、孔隙度、渗透率、饱和度和结论。
采用紧凑道头、细线、密网格、灰黄组分及窄结论条。颜色和自动刻度是展示规则，
不代表公司正式绘图标准或专业解释阈值。

原第 65 层资料只有 15 个采样点和部分原始曲线，不能呈现整井图的曲线密度；
没有逐点解释参数时相应图道显示未提供，不能拿层段平均值补齐整条曲线。

## 数据契约与链路

新增 `demo/log_plot.py` 从选定 Execution 的持久快照构造 `log_plot` 白名单，
`demo/read_models.py` 将其放进既有会话鉴权的执行详情 API。
不新建业务流程、不改变 W01–W10，也不把绘图放进大模型调用。

原始曲线使用 `raw_data.depths/curves`；W04、W05、W06（包括 `sw_result`）可在
`StageResult.result.curve_data` 提供专业逐点数据，结构复用已有 `RawData` 契约：

```json
{
  "curve_data": {
    "depth_unit": "m",
    "depth_reference": "MD",
    "depths": [2000.0, 2000.5, 2001.0],
    "curves": {
      "POR": {"unit": "fraction", "values": [0.12, null, 0.16]}
    }
  }
}
```

该字段由现有四阶段 Mock 提供者直接保留到状态；未来公司适配器也向此结构映射。
每条曲线携带名称、单位、来源、Mock 标识和自己的深度网格，按真实深度位置对齐，
不按数组序号对齐不同网格。层段仅使用 W08 中明确的 `top_depth_m`、`bottom_depth_m`、
`layer_type`，并可带 `formation`、`layer_no`、`lithology`。
取心道尚无数据契约，显示未提供；不得从自然语言岩心摘要推造取心深度。

## 数据边界

- 深度必须严格递增、样本长度必须对齐；异常专业曲线只形成绘图提示，不破坏报告读取。
- 空值断线；单点绘为点；对数坐标过滤非正值，图中明确提示。
- 不做单位转换、平滑、补点、重采样或专业参数计算。曲线连接仅作展示。
- 组分堆叠仅接受相同深度网格的 fraction 数据。负值、总量超 1 或缺项的采样段不填充，
  没有提供的剩余组分留白；VSH 不与 SH 重复堆叠。
- POR/PERM 的单值 Override 目前没有专业逐点复算，新版本隐藏对应旧曲线并提示待重算；
  历史版本保持原有数据。未来真实适配器接入时需同步调整此 Mock 边界。
- 单条曲线超过 20000 个深度点时暂不绘制并提示选择井段，不静默抽点。
- 当前输入通道仍是 Mock Fixture，图及导出明确标注 Mock，不能当作真实计算验证。
