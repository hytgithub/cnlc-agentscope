# 完整解释方法

完整解释按四个阶段组织：

1. 数据解编：准备可供解释使用的数据。
2. 数据预处理：整理并检查输入数据。
3. 智能处理：生成阶段性解释结果。
4. 报告生成：汇总本次解释输出。

只有用户明确要求解释整口井、从头解释或完整重做时，才考虑完整解释。先通过 `get_current_context` 获取当前 Fixture 的井标识，再调用 `start_full_interpretation`。单层查询、已有结果查看、报告读取和版本比较都不属于启动完整解释的理由。

这些阶段名称只用于 Task 012A 对照实验，不代表真实 Workflow 执行或专业计算。
